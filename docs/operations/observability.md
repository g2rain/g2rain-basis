# 可观测性

Actuator 当前暴露 `health` 和 `info`。生产环境应通过管理网络、网关或独立管理端口限制访问，不应无条件扩大端点范围。

建议观察：

- 租户开通各阶段成功、重复、失败、补偿和总耗时。
- IdP 快照拉取与同步的模式、规模、删除比例、安全闸拒绝、跨服务延迟和错误。
- Passport 解析/绑定、登录失败、密码更新和企业应用授权状态变化；指标不得暴露主体秘密。
- 权限聚合、路由定义查询和静态访问令牌解析的延迟、拒绝和缓存命中。
- 缓存失效事件发布失败、Kafka 审计消费失败/积压和重试。
- MySQL、Redis、Nacos、Kafka、IAM、Department 和服务注册健康。

日志应携带 trace/request 标识、可安全表达的机构及业务标识、阶段和错误码。不得记录密码、原始 Token、API Key、IdP 凭证、密钥或完整个人数据。
