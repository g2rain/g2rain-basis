## 参与贡献

欢迎通过 Issue、Discussion 和 Pull Request 参与 g2rain 建设。

代码贡献前请尽量补充必要的测试和文档，并确保构建、测试与静态检查通过。修改模块边界、调用关系、运行配置、代码生成流程或长期设计时，应同步更新项目文档或架构决策记录。

提交前至少执行：

```bash
mvn clean verify
```
